# Changelog

## 0.4.0 — 2026-10-20

Added an opt-in fixed-weight harness evolution command inspired by Evo²: shared Proposer/Reflector specification, autonomous and directed edits, strict keep/revise/crossover protocol, bounded parent/strategy pools, matched parent/child task evaluation, trusted mechanism-activation gating, per-task regression rejection, candidate archive refs, role usage records, and local compare-and-swap champion publication. Added a no-key evolution demo, Codex preparation example and evaluator protocol. No weight training or automatic scientific promotion is implemented. Existing task configuration fingerprints remain unchanged.

## 0.3.0 — 2026-10-17

Added opt-in parallel worker worktrees, bounded concurrency, atomic shared call reservations, sibling cancellation and interrupt cleanup, plan-order Git three-way integration, per-worker patches/merge evidence, optional bounded text-conflict resolvers, and an offline parallel demo. Unsupported binary/structural conflicts fail closed; final regression checks and review still gate publication. Added focused primary-documentation design review and setup flags. Existing sequential configs remain valid.

## 0.2.0 — 2026-10-17

Added Codex CLI worker/reviewer/planner adapters; explicit models and reasoning effort; schema-validated bounded sequential delegation with mixed Codex/command worker profiles; stage worker overrides; cumulative role-call limits; per-call JSONL usage records and configurable price estimates; `init-codex`, `doctor`, and `usage` commands. Preserved generic command tasks. Integration tests simulate the Codex CLI; live-model validation is pending.

## 0.1.0 — 2026-10-17

Initial local alpha generalized from a project-specific agent harness. Added provider-neutral command adapters, configurable stages, isolated attempts, full-stage regression checks, path policies, strict optional review, bounded retries, resumable state, reports, and offline code/data/report fixtures. Included public contribution materials and integration tests. No real-model benchmark or hosted package release is claimed.
